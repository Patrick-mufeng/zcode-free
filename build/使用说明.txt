ZCode 福利自动领取助手 · 使用说明
================================================

一、这是什么
------------------------------------------------
到点自动打开 ZCode 客户端 → 截图 → 视觉模型定位「领取」按钮 →
模拟点击 → 校验结果弹窗。失败会自动关客户端重开重试(默认 5 次)。
面板(浏览器里的那个页面)用来配置场次、查看日志与截图回放。

程序只在本机运行,截图与 API Key 都不会上传到任何第三方服务。


二、怎么启动
------------------------------------------------
双击 ZCodeAssistant.exe 即可,会自动用默认浏览器打开面板。

关闭浏览器不影响后台自动领取;要结束程序:
  · 面板里「设置 → 退出程序」,或
  · 在任务栏通知区域找到它并结束任务

注意:同一时间只能运行一个实例。重复双击会提示"已经在运行中",
这是有意设计——两个实例会把同一场次领取两次。


三、首次配置(面板里 4 步)
------------------------------------------------
1. 设置页:确认 ZCode 程序路径(点「自动探测」),窗口标题默认 ZCode 即可。
2. 识别页:填入 DeepSeek API Key(platform.deepseek.com 创建,需小额余额),
   点「连接与额度测试」;再点「测试识别」看模型能否框出领取按钮。
3. 场次表页:添加每天的时间场次(如 10:00 / 16:00),修改即刻生效。
4. 顶栏「总开关」打开。

建议先点「概览 → 演练一次」跑一遍(会置顶窗口并截图识别,但不点击、
不关客户端),确认能识别到领取按钮后,再点「试领一次(完整流程)」。


四、数据存在哪
------------------------------------------------
exe 同级的 data 文件夹:

  data\config.yaml    设置与 API Key(明文,请勿分享这个文件)
  data\logs\          运行日志,按天切分,默认保留 7 天
  data\shots\         每次尝试的截图留档,默认保留 7 天

如果 exe 放在 Program Files 这类没有写权限的位置,数据会自动改存到:
  %LOCALAPPDATA%\ZCode福利助手\data

整个文件夹一起复制就能搬到别的机器(onedir 打包,不能只拿 exe)。


五、系统设置建议
------------------------------------------------
程序会阻止系统与显示器休眠(否则到点了进程醒着、调度却不会触发),
但它阻止不了锁屏——锁屏是安全策略,不是电源策略。建议:

  · 屏幕保护程序:无
  · 锁屏超时:从不

一旦锁屏,该场次会被判为「需人工」并跳过,不会浪费重试次数。
如需"睡眠也能唤醒领取",要用 Windows 任务计划程序(勾选"唤醒计算机
运行此任务"),属另一套方案。


六、杀毒软件提示
------------------------------------------------
本程序没有代码签名,且会模拟鼠标点击,可能触发:

  · 首次运行弹「Windows 已保护你的电脑」→ 点「更多信息 → 仍要运行」
  · 杀软报可疑 → 把 ZCodeAssistant.exe 加入信任/白名单

请只从可信来源获取本程序。


七、常见问题
------------------------------------------------
问:总开关开着但不触发?
答:检查场次是否勾选启用、系统时间是否正确;日志页有每次触发记录。
   也确认电脑没有锁屏——锁屏时会跳过本场。

问:识别不准 / 点不到按钮?
答:识别页「测试识别」看红框位置;确认执行时窗口在前台、未被遮挡;
   必要时把福利页停到固定界面再调提示词与置信度阈值。

问:面板打不开?
答:先确认程序还在运行(看任务栏);端口默认 8760,被占用会自动顺延,
   实际地址以日志(或启动时的提示)为准。

问:不想要动画?
答:面板地址后加 ?motion=0,例如 http://127.0.0.1:8760/?motion=0
   想换浅色主题加 ?theme=light


八、合规提醒
------------------------------------------------
仅用于自动化本人账号、本机的福利领取,单场点击次数极少(≤5 次 + 校验)。
请遵守 ZCode 服务条款;若官方推出「一键领取」入口或条款禁止此类自动化,
请停用本工具。
