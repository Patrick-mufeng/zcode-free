# 方向 E — 静默方格 Quiet Bento

**一句话**：一块石墨色的专业仪器面板——没有渐变、没有光晕、没有一句废话，只有极其克制的 1px 细线、紧凑的小字号和一枚琥珀色信号灯。

**设计意图**：这是给"已经信任这个工具"的人用的形态。信息密度最高、装饰最少、长年开着不刺眼。它的高级感来自**对齐、留白节奏与精确的数字**，而不是视觉效果。适合当成每天常驻的桌面面板。

## 调色板

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0E0F11` | 底 |
| `--s1` | `#15171A` | 一级面（卡片） |
| `--s2` | `#1B1E22` | 二级面（输入框、悬浮） |
| `--hair` / `--hair-2` | `#24272C` / `#32363C` | 细线 / 强调线 |
| `--text-1/2/3` | `#E8EAED` / `#9AA1AA` / `#6B7280` | 主/次/弱 |
| `--amber` | `#E4A13C` | 唯一强调色：选中、主按钮、当前时刻 |
| `--ok / --err` | `#4FB477` / `#E0625C` | 成功 / 失败 |

**无渐变、无阴影、无模糊、无外发光。** 层次只靠 `--bg / --s1 / --s2` 三级底色差 + 1px 细线。强调色出现频率必须极低：整屏同时最多 2 处琥珀色。

## 字体

- 正文 `12.5px / 1.6`：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI"`
- 标题 `14px / 600`，不用大字号；页面标题 18px 顶格
- 数据 `Consolas`，字号和正文同档（12.5px），靠颜色和 tabular-nums 区分，不靠放大
- 卡片数值 22px / 500 / Consolas

## 圆角规则

`8px` 卡片 / `6px` 控件 / 全圆角 chip。克制，无例外。

## 布局

- 侧栏 216px：导航项 32px 高、圆角 6px、选中项底色 `--s2` + 左侧 2px 琥珀竖条（竖条用 `scaleY` 动效生长）
- 主区 `max-width 1400px`，栅格 12 列，**bento**：统计区用 `2fr 1fr 1fr 1fr` 的不等宽切片，主内容区左 8 右 4
- 卡片无边框（靠底色区分），只有需要分组时才用 1px 细线；表格无外框，表头一行细线 + 行间细线
- 密度：行高 32px，卡片内边距 14px，区块间距 14px（比别的方向紧一档）

**签名元素 · 24 小时轨道**：概览页顶部一条贯穿整宽的水平轨道，横轴 00:00 → 24:00，刻度每 2 小时一个；场次以竖线标记（启用=实线+琥珀点，未启用=虚线灰点），已执行场次在线下方挂结果小点（绿/红）；一枚琥珀色"现在"游标实时右移（每分钟走一格的速度，`ease: none`），游标处显示当前时间。鼠标悬停任一标记，弹出该场次的结果摘要。这是全屏唯一的动效焦点。

## 动效基调

- 时长 0.12~0.22s，缓动 `cubic-bezier(.2,.8,.2,1)`；GSAP 用 `power2.out`
- 开场：**细线先画出来**（`scaleX/scaleY 0→1`，0.4s stagger .04），内容随线上移 8px 淡入（0.24s），总时长 ≤ 1s；不许有大位移和弹跳
- 切页：内容 0.14s 交叉淡入 + 6px 上移，无滑动、无遮罩
- 执行中：状态灯是一枚 8px 琥珀灯，带一层极淡的 `box-shadow` 呼吸（唯一允许的"光"）；当前步骤行左侧 2px 琥珀条 `scaleY 0→1` 生长；步骤完成后琥珀褪为灰
- 数字：变化时用 0.35s 的数值滚动（不是翻牌），保持安静
- 实时日志：新行从 0.98 缩放 + 6px 下移进入（0.16s），行首一条琥珀竖线闪一次后消失
- 悬停：卡片**不做位移**，只有底色 `--s1 → --s2` 的 0.14s 过渡和描边变 `--hair-2`
- 只动 transform / opacity

## 禁止

渐变、发光、玻璃、大圆角、大字号、阴影、彩色图标、插画、空状态大白板；禁止在同一屏出现两处以上强调色；禁止任何超过 0.5s 的动画。
