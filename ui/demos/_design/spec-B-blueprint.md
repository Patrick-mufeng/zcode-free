# 方向 B — 制图台 Blueprint

**一句话**：把整个面板做成一张正在被绘制的工程图纸——深蓝底、24px 坐标格、尺寸标注线、箭头引线，每个节点都是一个可以量出来的符号。

**设计意图**：这个工具的本质是"精确执行一件事"，所以视觉上就该像 CAD 图纸一样可测量、可复查。用户看到红框坐标、看到标注出来的重试次数，就该相信它点得准。

## 调色板

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#071A2F` | 图纸底 |
| `--grid` | `rgba(120,190,255,.07)` 24px 网格，`rgba(120,190,255,.13)` 每 120px 主线 | 背景网格（固定层，不随滚动跳动） |
| `--line` / `--line-2` | `rgba(79,209,255,.22)` / `.45` | 轮廓线 / 强调线 |
| `--fill` | `rgba(79,209,255,.05)` | 极淡填充 |
| `--text-1/2/3` | `#CFE6FF` / `#8FB4D6` / `#5B7EA6` | 主/次/弱 |
| `--accent` | `#4FD1FF` | 制图青，用于引线、选中、主按钮描边 |
| `--ok / --warn / --err` | `#37E0B0` / `#FFC861` / `#FF7B72` | 语义 |

无玻璃、无阴影、无模糊。层次全靠**线宽**（1px 细 / 1.5px 主 / 2px 强调）与**填充浓度**（.03 / .05 / .08）区分。

## 字体

- 全站 `Consolas, "Cascadia Mono", monospace` 打底（这是图纸语言的核心）
- 中文因等宽字体不含汉字，回落 `"Microsoft YaHei UI"`，但**数字、坐标、时间、ID 一律 Consolas**
- 标题：`Bahnschrift SemiCondensed`，拉丁大写 + 字距 `.06em`；中文标题用雅黑 Semibold 14px
- 字号整体偏小：正文 12.5px、标注 11px、数值 18~26px

## 圆角规则

`2px`（技术件），chip 与状态点用 2px 直角或全圆角二选一后全站统一 —— **选 2px 直角**，只有状态灯是正圆。

## 布局

左侧栏 224px，导航项带序号（`01`~`06`，因为这里顺序真的有意义：它是操作顺序）；
主区顶部一条 32px 高的**标尺条**（刻度 + 当前页面名 + 图纸编号 `ZC-2026-09-10 / REV.1.1`）；
内容区右侧留一条 56px 的**标注栏**，页面切换时显示该页的图纸注释。

**签名元素 · 尺寸标注**：顶栏「下一场」不写倒计时，而是画成一把标尺——横向刻度尺，刻度 15/30/45/60 分钟，一枚三角索引箭头按剩余时间滑动，箭头旁标注 `T-02:13:09`。所有区块标题都用**带箭头引线**（`├────── 标题`）标注。

流程页的 7 个节点画成真正的**电气原理图**：正交折线连接、接点实心圆、节点框内是符号 + 名称 + 状态读数。

## 动效基调（GSAP）

- 缓动 `power2.out`，时长 0.3~0.45s，**干脆、可预测，不要弹跳**
- 开场：网格 0.6s 淡入；标尺刻度从左到右逐格"画"出（`scaleX` stagger）；轮廓线 `stroke-dashoffset` 描出；文字用 typewriter（每字 12ms）——**仅标题用，正文不许打字机**
- 流程页：连接线按路径顺序描出，节点在被连到时亮起（边框变强调色 + 填充加深）；执行中当前节点外框以 1.2s 周期"呼吸"并附读数
- 实时日志：逐行 typewriter 追加（每行 ≤ 40 字符，超过则直接出现），行尾一个闪烁光标块
- 状态：右上角一块**仪表读数框** `┌ STANDBY ┐`，执行中变 `┌ RUNNING · ATT 2/5 ┐`，字符逐位切换
- 只动 transform / opacity / stroke-dashoffset / clip-path

## 禁止

玻璃拟态、圆角卡片、渐变、阴影、emoji、任何"科技感线条装饰"（线必须承载信息：要么是网格，要么是标注，要么是分隔）。
