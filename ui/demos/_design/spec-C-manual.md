# 方向 C — 纸面手册 Paper Manual

**一句话**：像一本排版讲究的设备说明书 / 台账——冷白纸面、栅格严谨、页边留白充足，每次执行结果都在页面上"盖一个章"。

**设计意图**：这是唯一一个浅色方向。理由是用户白天用它查配置、对日志，浅色纸面比深色更耐读、更"可打印"；而"盖章"这个动作，把机器的一次成功变成一件有分量的事，缓解自动化的不信任感。

## 调色板

| token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F1F2EE` | 纸面（冷调微绿灰，**不是米黄/奶油**） |
| `--paper-2` | `#F8F9F6` | 卡片/浮层 |
| `--ink` | `#16191D` | 正文与主线条 |
| `--ink-2 / --ink-3` | `#5A6068` / `#8E9499` | 次/弱 |
| `--rule` / `--rule-2` | `#D8DAD3` / `#B9BCB4` | 细线 / 粗线（2px） |
| `--prussian` | `#1B3A6B` | 唯一强调色：选中、主按钮、链接 |
| `--ok / --warn / --err` | `#2F7D5B` / `#A8741A` / `#B33A2B` | 语义（墨绿 / 赭黄 / 朱红） |

**无渐变、无阴影、无圆角（0px）。** 层次靠：线宽（1px / 2px 双线）、墨色深浅、留白。

## 字体

- 标题：`"Microsoft YaHei UI", "Segoe UI"` 600，14~16px；拉丁标题 `Bahnschrift SemiBold` 大写 + 字距 `.04em`
- 正文：`"Microsoft YaHei UI", "Segoe UI"` 13px / 1.75（行高比别的方向大，是"读得久"的设计）
- 数据/编号：`Consolas`；**章节号、图号、页码一律 Consolas**
- 数字 tabular-nums

## 圆角规则

`0px`，全站唯一例外：印章是圆角与直角两种造型（成功=圆章、失败=方章），因为那是"物"，不是界面件。

## 布局

左侧是**目录式索引栏**（240px）：不是图标导航，而是带引导点线的目录——
```
§ 1  概览 ..................... 01
§ 2  流程 ..................... 04
§ 3  场次表 ................... 07
§ 4  识别 ..................... 09
§ 5  运行日志 ................. 12
§ 6  设置 ..................... 15
```
选中项左侧一条 3px 深蓝竖线 + 章节号变实心；条目右侧的页码由内容区真实滚动位置驱动更新（滚动时页码跟着变，这是这本"手册"的记忆点之一）。

正文区：`max-width 1080px`，左右留白 40px，章节标题上方一条 2px 双线（`border-top: 3px double`）。表格做成**账本样式**：只有横线没有竖线，表头下方一条 2px 线，行间 1px 点线。

页脚固定一条：`ZCode 福利助手 · 本地服务 127.0.0.1:8760 · 第 3 页 / 共 6 页`

**签名元素 · 印章**：执行结果不显示成 chip，而是盖一枚章。
- 成功 = 圆形朱印，双圈，内书 `领取成功`，旋转 -7deg，墨色 `--ok` 深绿（不是正红，红留给失败）
- 失败 = 方形朱红章 `领取失败` + `5 次未成`
- 需人工 = 长条章 `需人工处理`
盖章动效：从 `scale(1.7) rotate(-2deg) opacity 0` 砸到 `scale(1) rotate(-7deg)`，`back.out(2.2)`，配一次极短的"墨点扩散"（伪元素 scale 扩散 + 淡出 0.25s）。

## 动效基调

- 缓动 `power2.out`；盖章用 `back.out(2.2)`；翻页 0.35s
- 开场：章节线与引导点线依次"画"出（`scaleX` / `clip-path`），正文段落 `y:8 → 0` 淡入，stagger .04
- 切页：像翻纸——内容区 `rotateY` 太花，改为 `clip-path: inset(0 0 0 100%) → inset(0)` 的横向擦除，0.28s；退场 0.15s
- 高亮笔：新到的日志/记录行用一条 `--warn` 半透明色带从左到右扫过（`scaleX 0→1`，0.25s）后淡出，模拟荧光笔
- 倒计时：数字每跳一次有一次极轻的 `y:-1 → 0` 位移（0.12s），不许有弹跳感
- 状态灯：不用发光圆点，用一枚小方块墨印，执行中做 `opacity .35↔1` 的呼吸

## 禁止

渐变、阴影、玻璃、圆角卡片、发光、emoji、任何形式的"深色模式补丁"。也要避免做成"报纸大标题"——标题层级要克制，靠编号和留白，不靠字号爆炸。
