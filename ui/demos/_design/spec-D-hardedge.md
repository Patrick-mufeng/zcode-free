# 方向 D — 硬边运维 Hard Edge

**一句话**：把控制台做成一台硬塑料外壳的工业设备——纯白机身、2px 黑框、硬投影、机械摇杆开关，按下去要有"咔"的位移。

**设计意图**：自动化工具最大的风险是"我以为它在跑，其实它挂了"。这个方向用最不可能被误读的方式表达状态：巨大的色块、硬边框、盖章一样的状态贴纸。所有可点的东西都长得像可以按下去。

## 调色板

| token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FBFBF7` | 机身白 |
| `--ink` | `#0E0E11` | 边框、文字、硬投影 |
| `--ink-2` | `#4A4A52` | 次级文字 |
| `--cobalt` | `#2B3BFF` | 唯一的行动色：主按钮、选中、链接 |
| `--signal` | `#FF4D2E` | 危险 / 失败 |
| `--lime` | `#00A86B` | 成功 |
| `--sun` | `#FFCC00` | 警告 / 重试 / 等待 |

**规则**：所有实体（卡、按钮、输入框、表格）都是 `2px solid var(--ink)` + `box-shadow: 4px 4px 0 var(--ink)`，无模糊、无渐变、无透明度修饰。圆角 `0px`。大面积色块（成功/失败贴纸、状态条）直接用满饱和度纯色，这是它"响"的来源。

## 字体

- 标题：`"Arial Black", "Segoe UI", sans-serif`（或 `font-weight: 900`），中文回落雅黑 900（若不可用则 700）
- 拉丁标签：大写 + `letter-spacing: -0.01em`，字号 11px
- 正文：`"Segoe UI", "Microsoft YaHei UI"` 13.5px / 1.55
- 数字：`Consolas` 加粗，`tabular-nums`

## 圆角规则

`0px` 全站。唯一例外：状态贴纸有 2px 圆角（模拟裁切）。

## 布局

- 顶栏高 68px，底部 2px 黑线；侧栏 236px，右侧 2px 黑线；导航项是**厚按钮**，选中项整块反白（黑底白字）并向左突出 6px
- 卡片网格用 2px 黑线分隔（`gap: 2px` + 背景黑色制造"印刷分隔线"效果，比逐卡描边干净）
- 表格：表头黑底白字大写，行间 2px 线，`hover` 整行 `--sun` 15% 底
- 主按钮：`--cobalt` 实底白字 + 4px 硬投影；`:active` 时 `translate(3px,3px)` 且投影缩到 1px——物理按键

**签名元素 · 工业摇杆开关**：顶栏总开关不是小胶囊，而是一枚 56×34 的物理摇杆——黑框、内部滑块 34×26 带 2px 边框和硬投影，OFF 时滑块在左且底面 `--ink`，ON 时滑块滑到右且底面 `--lime`。切换时滑块带 `back.out(2)` 的过冲 + 一次整体的 1px 抖动。

**签名元素 · 状态贴纸**：状态灯换成贴纸——`空闲` 灰底黑字、`执行中` 钴蓝底白字（带 1s 脉冲）、`成功` 绿底白字、`需人工` 朱红底白字。贴纸旋转 -2deg，4px 硬投影，状态切换时贴纸先"揭起"（`y:-6, rotate:-6`, 0.12s）再"拍下"（`y:0, rotate:-2`, `back.out(2.4)`）。

## 动效基调

- 极短、极硬：微交互 0.1~0.18s，入场 0.3s，`power4.out` / `back.out(2)`
- 开场：面板从四边"推进来"——每块 `clip-path: inset(...)` 收拢 + `x/y` 归位，stagger .05；不用淡入（淡入太柔），用硬切 + 位移
- 切页：新页面整块从右侧 24px 推入，0.22s；导航选中块用 `steps` 感的快速滑动 0.16s
- 执行中：步骤胶囊完成时"打勾"用一个 0.2s 的 `scale 1→1.25→1` + 色块填充；失败步整块变 `--signal` 并抖动 3px 两次
- 数字：变化时整块 `y` 翻动（上下两半各翻 90deg 太重，改用 0.15s 的 `y:6→0 opacity`），保持机械感
- 计时条：执行中用一条 4px 的 `--cobalt` 进度条横扫，走完一轮 1.4s
- 只动 transform / opacity / clip-path

## 禁止

渐变、模糊、玻璃、柔和阴影、细线（1px 一律改 2px）、半透明色块、emoji、圆润字体、任何"高级感"的克制手法——这个方向要吵、要直接、要在三米外看清状态。
