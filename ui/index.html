识别逻辑 两次模型调用 + 若干本地判定
01截图本地 · 无网络
  • 先置顶 ZCode(必要时复位窗口位置),再抓屏
  • mss 全屏抓取 → 按窗口矩形裁剪出「窗口图」
  • 锁屏由系统 API 判定;纯色画面视为「未渲染」,继续等待
02定位 · 模型调用 ①DeepSeek 视觉
  • 输入:窗口图 + 定位 Prompt(要求只输出 JSON)
  • 输出:scene / claimable / already_claimed / button_found / button_box(归一化 0~1) / ocr_texts / confidence / notes
  • 结构化保障:Prompt 含 JSON 示例 + response_format + 本地 JSON 修复
03点击本地
  • 取 button_box 中心 → 归一化坐标
  • 屏幕坐标 = 窗口矩形原点 + 归一化 × 矩形尺寸
  • pyautogui 点击(鼠标甩到左上角可急停),等 2.5 秒后校验
04校验 · 模型调用 ②DeepSeek 视觉
  • 结果以弹窗呈现:成功 =「领取成功 + 开始体验」,失败 =「领取失败 + 知道了」
  • 再次置顶 + 截图,送入校验 Prompt
  • 输出:success / failed / popup / keywords / confidence / notes
判定规则 模型给「观察」,规则做「决策」
阶段判据动作
定位场景 = 登录页 / 验证码等异常界面需人工,立即停止本场
定位已领标记为真,或命中「已领词」(如:明日再来)按已领取收尾,不再点击
定位找到按钮 且 可领 且 置信度 ≥ 阈值(默认 0.70)执行点击,进入校验
定位以上都不满足(没找到 / 置信度不足)未成功 → 关客户端重试
校验成功弹窗:含「领取成功」或「开始体验」成功,留档 + 通知
校验失败弹窗:含「领取失败」或「知道了」未成功 → 关客户端重试
校验claimed 为真,或命中「已领词」按已领取收尾
校验没有弹窗、与点击前无明显变化未成功 → 关客户端重试
坐标换算 为什么用归一化坐标
窗口矩形由程序摆放或实测x=40, y=40, w=1240, h=860
+
归一化中心点模型返回的 button_box 中心cx=0.50, cy=0.65
=
屏幕坐标交给 pyautogui 点击x = 40 + 0.50 × 1240 = 660y = 40 + 0.65 × 860 = 599

视觉模型内部会把图缩放到约 800×800 等效,像素坐标含义不确定,所以统一用「相对整图的 0~1 比例」;normalize_box() 还兼容模型偶尔返回百分比或像素值的情况。
