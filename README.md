# ZCode 福利自动领取助手

到点自动打开 ZCode 客户端 → 截图 → DeepSeek 视觉模型定位「领取」按钮 → 模拟点击 → 视觉校验结果(弹窗);
未成功则关闭客户端、5 秒后重开,最多 5 次;全部失败则记录并等待下一场次。

配套文档:[技术方案](ZCode福利助手-技术方案v1.md) · [UI 设计方案](ZCode福利助手-UI设计方案v1.md)

## 快速开始

```bat
:: 仅首次:创建虚拟环境并安装依赖(已装好可跳过)
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

之后全部**双击即用**:

| 双击 | 作用 |
|---|---|
| `selftest.bat` | 环境自检(无需 API Key,11 项检查,约 15 秒) |
| `probe.bat` | 环境侦察:定位 ZCode.exe 并截一张当前福利页图 |
| `run.bat` | 启动面板,按场次常驻自动领取 |
| `dry-run.bat` | 演练模式:截图、识别、走流程,但**不点击、不关闭客户端** |

> 面板就是本地服务(`http://127.0.0.1:8760/`),启动时自动用默认浏览器打开;关闭浏览器不影响后台自动领取,端口被占用会自动顺延(地址以日志为准)。结束程序按 Ctrl+C,或用面板「设置 → 退出程序」。
>
> 以上 `.bat` 均为**纯 ASCII 文本**:cmd.exe 按系统代码页解析批处理文件,把中文写进 .bat 在中文 Windows 下会导致整段乱码、命令全部失效——需要改提示语时请用英文,或另存为 ANSI 编码。

## 首次配置(面板里 4 步)

1. **设置页**:确认 ZCode 程序路径(点「自动探测」),窗口标题匹配默认 `ZCode` 即可。
2. **识别页**:填入 DeepSeek API Key([platform.deepseek.com](https://platform.deepseek.com) 创建,需小额余额),
   点「连接与额度测试」;再点「测试识别」看模型能否框出领取按钮(框错就检查是不是没停在福利页)。
3. **场次表页**:添加每天的时间场次(如 10:00 / 16:00),修改即刻生效。
4. 顶栏**总开关**打开。建议先在「概览 → 手动测试」点「**演练一次**」跑一遍(会先把客户端置顶再截图识别,但不点击、不关客户端),确认能识别到领取按钮后,再点「试领一次(完整流程)」。

> 想先不动真格?用 `run.bat --dry-run` 启动:会截图、会识别、会走完流程,但**不点击、不关闭客户端**。

## 运行方式

| 命令 | 说明 |
|---|---|
| `run.bat` | 启动服务并用默认浏览器打开面板,后台按场次自动领取 |
| `run.bat --dry-run` | 演练模式(不点击、不关客户端) |
| `run.bat --run-now` | 启动后立即试领一次 |
| `run.bat --no-open` | 只启动服务,不自动打开浏览器 |
| `run.bat --headless` | 不启动 Web 服务,仅按场次调度 |

## 目录结构

```
core/        后端:配置/调度/执行状态机/截图/点击/视觉/判定/通知/存储/API/HTTP 桥
ui/          Web 面板前端(纯静态 HTML/CSS/JS,离线可用)
data/        运行时数据(config.yaml、logs/ 日志、shots/ 截图留档)
main.py      入口      probe.py 环境侦察      selftest.py 自检
```

## 工作原理

1. 场次到点(APScheduler)→ 打开/复用 ZCode 窗口,先等界面加载(默认 5 秒),再把窗口**最大化(全屏)**并置前;
2. 截图前会等待"界面渲染完成":锁屏由系统 API 判定(真的锁屏才跳过本场);画面还是纯色则视为"加载中",默认最多等 20 秒,期间每轮重新置顶;
3. mss 截全屏 → 裁出窗口区域 → 发给 DeepSeek 视觉模型,要求返回 **归一化坐标**;
4. 置信度 ≥ 阈值才点击(坐标换算 = 窗口 rect + 归一化值);
5. 点击后等 2.5s 再截图 → 模型判断结果弹窗:**成功弹窗 =「领取成功 + 开始体验」,失败弹窗 =「领取失败 + 知道了」**;
6. 成功 → 留档 + 通知(保留客户端窗口);失败弹窗或无变化 → 关闭客户端 → 等 5s → 重开重试(最多 5 次);识别到登录页等"需人工"界面则立即停止并通知。

## 常见问题

- **找不到 ZCode.exe**:设置页手动填完整路径,或先手动打开一次客户端(运行中的进程可直接读出路径)。
- **识别不准 / 点不到按钮**:用识别页「测试识别」看红框位置;确认执行时窗口在前台、未被其他窗口遮挡;必要时把福利页停到固定界面再调提示词。
- **锁屏/休眠会失败**:真的锁屏时程序会跳过本场并通知(锁屏用系统 API 判断,不会把"客户端正在加载"误判成锁屏);请保持电脑处于解锁且不睡眠状态。
- **总开关开着但不触发**:检查场次是否勾选启用、系统时间是否正确;日志页有每次触发记录。
- **双击 .bat 报 "xxx 不是内部或外部命令" 并伴随乱码**:该 .bat 被保存成了 UTF-8 中文。项目自带的 .bat 已改为纯 ASCII;若你自行编辑过,请另存为 ANSI 编码或改回英文。
- **面板打不开**:先用 `run.bat --no-open` 启动,再手动访问日志里打印的地址(默认 8760,被占用会自动顺延);浏览器建议用 Edge/Chrome。
- **不想要动画**:访问地址后加 `?motion=0`(如 `http://127.0.0.1:8760/?motion=0`);系统开启"减少动态效果"时也会自动禁用。
- **杀软拦 pyautogui**:把 `.venv\Scripts\python.exe` 加入信任,或用 --dry-run 验证非点击链路。

## 合规提醒

仅用于自动化**本人账号、本机**的福利领取,单场点击次数极少(≤5 次 + 校验),请遵守 ZCode 服务条款;
若官方推出「一键领取」入口或条款禁止此类自动化,请停用本工具。
